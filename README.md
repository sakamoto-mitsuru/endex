## 公開する

リポジトリ `endex` の中身を丸ごと入れ替えて push。
Settings → Pages は `main` / `(root)` のままで構いません。

## index.html に加えた点

元のファイルから変えたのは次だけです。**見た目の骨格・巡回する絵・体験するボタンはそのままです。**

- `<head>` に manifest・theme-color・apple 用のメタ・アイコンを追加
- Service Worker の登録と、ホーム画面追加の案内（Androidのみ表示）
- 足元に「装いとお棺の取り合わせを見る」のリンクを追加
- 小さかった文字を上げた（ブランド 12→15px、説明文 12〜14→16〜19px、工程名 11.5→15px、注記 12→16px）

「体験する」の遷移先 `./demo.html` は変えていません。PostHog の `kv3_demo_start` もそのままです。

## ホーム画面に追加する

| | 手順 |
|---|---|
| iPhone / iPad | Safariで開く → 共有ボタン → 「ホーム画面に追加」 |
| Android | Chromeで開く → 足元の「追加する」を押す |

**iOSに自動の案内は出せません。** OSが対応していないため、共有メニューからの操作になります。

## 会場での注意

**前日までに、会場で使う端末で `index` `demo` `pair` の3つを開いてください。** 一度開けば端末に残るので、当日に電波が切れても動きます。開いていない画面は真っ白になります。

`demo.html` は22MBあります。**最初の読み込みだけは時間がかかります。** 会場のWi-Fiでその場で開くのは避けてください。

**古いService Workerが残っている端末に注意。** すでに一度開いた端末では、上げ直しても前の画面が出続けることがあります。Chromeなら DevTools → Application → Service Workers → Unregister、iOSならSafariの履歴とWebサイトデータを消去。会場で使う端末で一度やっておいてください。

## 差し替えたとき

モックを更新したら `sw.js` の版を上げてください。

```js
const CACHE = 'ceremony-preview-v1';   // → v2
```

**上げないと、端末に残った古い画面が出続けます。**
