# セレモニープレビュー ｜ 展示用サイト

エンディング産業展（2026年9月11日・Ariake GYM-EX）向けの試作。
静的ファイルだけで動きます。サーバー側の処理はありません。

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | トップ。2つの画面への入口 |
| `flow.html` | 画面の流れ（取り込み〜祭壇まで通し）。22.7MB |
| `pair.html` | 装い4×お棺4の16通り。11.3MB |
| `manifest.webmanifest` | ホーム画面に追加するための定義 |
| `sw.js` | 一度開いた画面を端末に残す |
| `icon-*.png` / `apple-touch-icon.png` | アイコン |

画像はすべてHTMLに埋め込んであります。外部への通信はありません。

## GitHub Pages で公開する

1. リポジトリを作り、このフォルダの中身をそのまま置く
2. Settings → Pages → Source を `Deploy from a branch`、Branch を `main` / `(root)`
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開く

`docs/` の下に置く場合は Branch を `main` / `/docs` にしてください。

**PWAには HTTPS が要ります。** GitHub Pages は最初からHTTPSなので、そのまま動きます。

## ホーム画面に追加する

| | 手順 |
|---|---|
| iPhone / iPad | Safariで開く → 共有ボタン → 「ホーム画面に追加」 |
| Android | Chromeで開く → トップに出る「追加する」を押す（またはメニュー →「アプリをインストール」） |

追加すると、アドレスバーの無い画面で開きます。

**iOSでは「追加する」のボタンは出ません。** OSが対応していないためで、共有メニューからの操作になります。

## 会場での注意

**前日までに、会場で使う端末で一度すべての画面を開いてください。** 一度開けば端末に残るので、当日に電波が切れても動きます。開いていないと、その画面だけ真っ白になります。

`flow.html` は22MBあります。**最初の読み込みだけは時間がかかります。** 会場のWi-Fiでその場で開くのは避けてください。

## 差し替えたとき

モックを更新したら、`sw.js` の1行目にある版を上げてください。

```js
const CACHE = 'ceremony-preview-v1';   // → v2
```

**上げないと、端末に残った古い画面が出続けます。** ここだけは忘れると当日に効いてきます。
